# Contributing

This guide covers working on this connector. For general Splunk SOAR app guidelines, see the [SOAR App Contribution Guide](https://github.com/splunk-soar-connectors/.github/blob/main/.github/CONTRIBUTING.md).

> `README.md` is the app's user-facing documentation and is generated by pre-commit. Don't edit it for development notes.

## Setup

```powershell
# 1. Create and activate a virtual environment
python -m venv .soar
.\.soar\Scripts\Activate.ps1

# 2. Install pre-commit
python -m pip install -U pip pre-commit

# 3. Install the Git hooks (once per clone)
pre-commit install

# 4. Run all checks
pre-commit run --all-files
```

## Release notes

Add a bullet for your change to `release_notes/unreleased.md`. Don't edit the numbered files (`1.0.0.md`, …); they're created at release time.

## Troubleshooting

### 1. Hook environment install fails with `PermissionError: [WinError 5] Access is denied`

**Cause:** on Windows, antivirus scanning locks pip's files while `virtualenv` renames its cache folder. It happens when hook environments are built: on the first run, or after a Python, pip or hook version change.

**Fix:** clear the partial caches and rebuild with the `pip` seeder, which skips that rename:

```powershell
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\pypa\virtualenv" -ErrorAction SilentlyContinue
pre-commit clean
$env:VIRTUALENV_SEEDER = "pip"; pre-commit run --all-files
```

Once the environments are built, later runs don't need the variable. To set it permanently, run `setx VIRTUALENV_SEEDER pip`.

### 2. Hooks fail during `pre-commit run`

CI still runs any hook you skip locally.

#### `static-tests`: `IndexError: list index out of range`

**Cause:** the hook splits file paths on `/`, which fails with Windows `\` paths.
**Fix:** skip it, or run pre-commit from WSL.

#### `package-app-dependencies`: `Please ensure Docker is installed and running`

**Cause:** the hook builds dependency wheels in a Linux container.
**Fix:** start Docker Desktop, or skip it if you didn't change dependencies.

#### `semgrep`: `TypeError: Metaclasses with custom tp_new are not supported`

**Cause:** semgrep's pinned protobuf is incompatible with Python 3.14. The `x509 ... negative serial number` warnings are harmless.
**Fix:** skip it, or run pre-commit from a Python 3.13 (or earlier) environment.

#### Skip all of the above

```powershell
$env:SKIP = "static-tests,package-app-dependencies,semgrep"; pre-commit run --all-files
```

`SKIP` stays set for the terminal session, so `git commit` in the same terminal skips these hooks too. Clear it with `Remove-Item Env:SKIP`.
